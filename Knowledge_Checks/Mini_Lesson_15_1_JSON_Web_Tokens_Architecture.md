# Mini-Lesson 15.1 – JSON Web Tokens (JWT) Architecture

## Overview

A JSON Web Token (JWT) is a secure mechanism used to exchange information between a client and server.

JWTs provide:

- Authentication
- Authorization
- Session management
- Secure transfer of user information

JWTs allow a web application to remember information about a user while the application is running without constantly requiring the user to log in again.
