# Project 15.1 - Creating a Books Web Application

## Overview

This project extends the concepts introduced in Module 11 by developing a web application that manages a collection of books while incorporating authentication and authorization using JSON Web Tokens (JWT).

The application demonstrates how modern web applications securely control user access and permissions through token-based authentication.

---

## Objectives

- Create a books web application.
- Implement JWT authentication.
- Implement user authorization.
- Support multiple users.
- Apply role-based access control (RBAC).
- Add book images and metadata.
- Restrict actions based on user roles.

## Security Concepts

### Authentication

Verifies user identity.

### Authorization

Verifies user permissions.

### JWT

Provides a secure mechanism for maintaining authenticated sessions.

### RBAC

Role-Based Access Control allows different users to perform different actions.
